# 技能授权与排班管理（SkillShift）

面向生产班组的本地小系统：每道工序维护技能等级、培训记录、考核日期与授权期限；
排班只允许合格人员上对应设备；临时替岗必须说明原岗位空缺与授权依据，并按风险分级复核。

零第三方依赖：Python 3 标准库（`http.server` + `sqlite3`）+ 原生 HTML/CSS/JS。

## 一条命令启动

```bash
./run.sh                 # 默认 http://127.0.0.1:8077
PORT=9000 ./run.sh       # 换端口
RESET=1 ./run.sh         # 清空本地数据并重新生成样例
```

首次启动自动建库（`app/data/shift.db`，SQLite + WAL）并注入样例数据：

- 4 道工序（焊接/冲压为高风险）、5 台设备（含同工序不同型号 WX-200/WX-300）
- 2 名班长（陈晨、李立）、1 名安全负责人（安平）、1 名培训老师（傅师）
- **夜班 `PKG-01` 包装岗存在一条“无证替岗”样例**：班长李立为无授权新人钱新申请替岗，
  岗位空缺原因为“原岗郑包请病假”，等待安全负责人安平复核
- 王焊的 WX-200 授权 10 天后到期（到期提醒样例）
- 赵强 WX-300 考核未通过且处于成绩申诉中（申诉样例）
- 王焊包装授权被临时撤销、冲压考核未通过（负向样例）

考核附件保存在本地 `app/data/attachments/`；通知由进程内后台线程每 2 秒投递一轮，
并写入模拟回执号 `SIM-RCPT-…`（无任何外部服务）。

## 五个视图

| 视图 | 内容 |
|---|---|
| 技能矩阵 | 工序为行、员工为列；单元格直接显示等级 L1–L3、型号范围（“全型号”/具体型号）与授权到期日；15 天内到期为浅黄底，过期/撤销/型号不覆盖以文字提示（不用大片红底） |
| 排班 | 选择日期白班/夜班；顶部汇总缺口与无证派工数量；每个设备槽位下方同屏列出可替人员（划线表示该班次已在其他设备），拖拽派工 |
| 替岗申请 | 空缺原因、拟替人员、授权依据（授权 id 或“无证”）、申请班长、复核人与意见 |
| 培训证据 | 考核登记（可传附件）、审批、成绩申诉、授权临时撤销、设备型号变更及影响人员检查 |
| 到期提醒/通知 | 15 天内到期授权清单；通知队列与模拟送达回执 |

界面配色：工业白 + 深灰为主，克制的黄色只用于“到期/待复核/高风险”提示；
异常状态用浅红描边/文字与左侧红色边线标识，不整行铺红底。

## 业务规则

- **授权时段**：派工日必须落在 `valid_from … valid_to` 内；过期、未生效、撤销均不合格。
- **设备型号匹配**：精确型号授权优先；`model=NULL` 为全型号通用授权。设备换型后，
  只有精确型号授权的员工立即失去资格，通用授权不受影响（矩阵中提示“不含型号 …”）。
- **排班冲突**：同一员工同一班次只能占用一台设备。两名班长同时占用同一员工同一时段时，
  后提交者收到 409 冲突，返回先派的班长、设备与提交时间。拖拽员工从自己原槽位移动到
  新槽位属于“移动”（携带 `from_assignment_id`），原槽位自动清空；目标槽已被他人占用
  时拒绝无声顶替。
- **无证派工拦截**：直接拖拽无资格人员会被 422 拦截，必须改走替岗申请；
  申请带 `unlicensed` 依据时只有安全负责人能复核，批准后以“无证派工”警告留痕落班。
- **高风险设备**：焊接/冲压的替岗必须安全负责人复核，普通班长复核被拒。
- **职责分离**：
  - 培训老师不能审批自己登记的考核（须他人审批，通过后才签发授权）；
  - 替岗申请人不能复核自己的申请；
  - 考核申诉不能由原登记人处理；支持申诉则改判通过并签发授权。
- **触发事件**：技能到期（自动扫描入通知队列）、考核未通过（不产生授权）、
  设备型号变更（列出受影响人员并发通知）、夜班缺员（缺口可见）、临时撤销（即时失效）、
  培训成绩申诉（进入待处理状态）。

## API 摘要

```
GET  /api/state                          基础数据 + 技能矩阵
GET  /api/shifts/{id}/view               班次视图：槽位状态 + 每台设备可替人员
POST /api/assignments                    派工（含 from_assignment_id 移动语义）
POST /api/assignments/vacate             清空槽位
POST /api/substitutions                  班长申请替岗（必须含 vacancy_reason）
POST /api/substitutions/{id}/review      复核（高风险/无证须安全负责人）
POST /api/assessments                    multipart 登记考核 + 证据附件
POST /api/assessments/{id}/approve       审批（登记人不可审）
POST /api/assessments/{id}/appeal        本人发起成绩申诉
POST /api/assessments/{id}/appeal/resolve
POST /api/authorizations/{id}/revoke     临时撤销
POST /api/equipment/{id}/model           换型，返回失去资格人员
GET  /api/expiring  /api/notifications   到期清单 / 通知与回执
POST /api/notify/pump                    立即投递一轮（测试/演示用）
```

覆盖（21 个用例）：

- 授权时段：在期、过期、未生效、撤销、考核未通过不授权
- 设备型号：精确匹配、全型号通用、换型后仅精确授权者失效
- 排班冲突：两名班长同时段争用同一员工（后提交者看到冲突及先派信息）、
  跨班次不冲突、非班长不能派工、无证直接派工被拦截
- 职责分离：培训老师自审被拒、申请人自核被拒、高风险须安全复核、
  无证替岗须安全复核且批准后带警告、空缺原因必填
- 申诉改判、撤销即时生效、到期扫描与模拟回执、矩阵结构与内容
