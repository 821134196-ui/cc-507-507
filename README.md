# 制造车间 · 技能矩阵与排班授权系统

零第三方依赖（Python 3.11 标准库 + 原生 HTML/JS）：SQLite 保存授权与班次，考核附件存本地，
到期提醒使用进程内守护线程 + 模拟回执。

## 一条命令启动

```bash
python3 run.py              # http://127.0.0.1:8000
python3 run.py --reset      # 删除并重建演示库（推荐首次体验）
python3 run.py --port 8123 --interval 30
```

启动后控制台会提示内置样例：**今日夜班 EQ-04 高风险焊位有一条「无证替岗」申请待安全负责人复核**。

数据文件：`data/app.db`；考核/培训附件：`data/attachments/`。

## 页面

| 页面 | 内容 |
|---|---|
| 技能矩阵 | 工序为行、员工为列；格内直接显示 `等级 / 有效期至 / 型号`。绿=有效、黄=7 日内到期、灰虚框=到期/暂停/撤销 |
| 排班拖拽 | 每个工位卡片同屏显示：在岗人、缺口、**可替合格人员**、不可直接排入者及原因（到期/未通过/型号不符/已占用）；支持 HTML5 拖拽与「排入」按钮 |
| 替岗申请与复核 | 班长才能发起，必填原岗位空缺说明与授权依据；普通设备由**另一名班长**复核，◆高风险设备由**安全负责人**复核，申请人不能自审；无证替岗批准后落班但不洗白资格，全程留痕 |
| 培训证据 | 考核登记（培训老师）→ 他人审批；本地上传成绩单/培训附件；未通过考核可本人申诉、他人裁决（登记人不能裁决自己登记的考核） |
| 到期提醒 | 进程内任务每 60s 扫描（可 `--interval` 调整）：到期授权自动置 expired 并停止排岗，7 日内到期发提醒；每条通知有模拟回执 `SIM-NTF-xxxx` |

## 业务规则落点

- **授权时段**：`valid_from <= 当日 <= valid_until` 且 `status=active`，等级 ≥ 设备要求。
- **设备型号匹配**：授权绑定型号（`NULL` = 该工序全型号）；设备型号变更后旧型号专属授权不再覆盖，须重新培训考核（见 `equipment_changes` 留痕）。
- **排班冲突**：SQLite 唯一索引 `(employee_id, shift_id)` + 服务层预检；同一员工同一班次只能占一个工位，已有待批替岗也冲突——两名班长先后为同一员工同时段提交，后者立即看到冲突原因。
- **考核未通过 / 申诉**：最近一次同工序考核 fail（申诉未裁决成立）即阻断排班；申诉中不放行。
- **临时撤销**：授权 `revoked/suspended` 立即失去资格，撤销事件入 `auth_events`。
- **职责分离**：班长申请、安全复核高风险、培训老师不能审批/裁决自己登记的考核。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：授权时段（未生效/有效/到期）、设备型号匹配（专属/全型号/换型/等级）、
排班冲突（跨工位、跨班长并发、待批申请占位）、职责分离（申请权限、高风险复核、自审禁止、
培训师自批禁止、申诉裁决回避）、无证替岗（审批可覆盖资格缺口但不能覆盖冲突）、HTTP 端到端冒烟。

## 结构

```
app/db.py        # SQLite schema + 种子数据
app/rules.py     # 资格判定 / 冲突预检 / 职责分离（纯查询）
app/services.py  # 排班、替岗审批、申诉、换型、到期扫描线程、通知回执
app/server.py    # 标准库 HTTP：JSON API + multipart 上传 + 静态页面
app/static/      # index.html / styles.css / app.js（原生 JS 拖拽）
tests/test_rules.py
run.py           # 入口
```
